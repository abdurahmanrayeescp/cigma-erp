# CIGMA ERP: Administrator Guide

Welcome to the Administrative Guide. This document provides an overview of the key responsibilities and tools available to the `SUPER_ADMIN` and `ADMIN` roles within the CIGMA digital ecosystem.

## 1. Access & Dashboard
- Navigate to `https://portal.creativecigma.com` or `https://admin.creativecigma.com`.
- Log in using your designated `SUPER_ADMIN` credentials.
- The sidebar grants access to system modules based on your role.

## 2. Managing Users & Data
- **Enrollment**: Use the Data Migration scripts to bulk-import new batches of students and staff, or use the interactive UI to manually onboard individuals.
- **Fees**: Track student fee payments, pending dues, and issue digital receipts.
- **Payroll**: Generate monthly payroll batches for teachers, track deductions, and mark salary distributions as "paid".

## 3. Communication
- **Notifications**: Dispatch global push notifications or targeted messages to specific roles (e.g., all Parents, all Teachers).
- **News & Gallery**: Update the public website's News ticker and Photo Galleries directly from the dashboard. Changes reflect immediately on `creativecigma.com`.

## 4. Academic Operations
- **Certificates**: Generate and download verified Transfer Certificates (TC) and Bonafide documents dynamically using the Certificate Generator tool.
- **Reporting**: Export granular CSV datasets of student performance and attendance via the Advanced Reports module.

## 5. Security & Auditing
- **Audit Logs**: Only accessible by Super Admins. The Audit Log tracks every significant data mutation (creation, deletion, updates) across the platform, including the user responsible and their IP address.
